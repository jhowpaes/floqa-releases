# Floqa — Releases

This repository hosts the official releases for **[Floqa](https://floqa.app)** — an API testing and web automation desktop app for macOS, Windows and Linux.

> Source code is maintained in a private repository. This repo exists solely for distributing signed builds and powering the in-app auto-updater.

## Download

| Platform                          | File                        |
| --------------------------------- | --------------------------- |
| **macOS** (Apple Silicon + Intel) | `Floqa-x.x.x-universal.dmg` |
| **macOS** (Intel only)            | `Floqa-x.x.x.dmg`           |
| **macOS** (Apple Silicon only)    | `Floqa-x.x.x-arm64.dmg`     |
| **Windows**                       | `Floqa Setup x.x.x.exe`     |
| **Linux** (any distro)            | `Floqa-x.x.x.AppImage`      |
| **Linux** (Debian/Ubuntu)         | `floqa_x.x.x_amd64.deb`     |
| **Linux** (Fedora/RHEL)           | `floqa-x.x.x.x86_64.rpm`    |

→ **[Download latest release](https://github.com/jhowpaes/floqa-releases/releases/latest)**

## Auto-update

Floqa checks this repository for updates automatically. When a new version is available, the app notifies you and installs it on next restart.
